# Fantasy Name Generator

A procedural name generator for fantasy RPG characters. Generates names for humans, elves, dwarves, and orcs using syllable combination from curated databases.

## Features

- **4 races supported**: Human, Elf, Dwarf, Orc
- **6.25 million+ unique combinations** per race
- **Seeded generation** for reproducible results
- **Dual-use design**: Works as CLI tool or Python library
- **No dependencies**: Pure Python 3, standard library only

## Installation

```bash
# Clone or download
git clone https://github.com/yourusername/fantasy-name-generator.git
cd fantasy-name-generator

# No installation needed - just run it
python namegen.py human
```

## Usage

### Command Line

```bash
# Generate 10 human names (default)
python namegen.py human

# Generate 20 elf names
python namegen.py elf -n 20

# Generate 5 dwarf names with seed (reproducible)
python namegen.py dwarf -n 5 --seed 12345

# Generate 15 orc names
python namegen.py orc -n 15

# See all options
python namegen.py --help
```

### As a Library

```python
from namegen import NameGenerator

# Create generator
gen = NameGenerator()

# Generate single names
human_name = gen.generate_human_name()
elf_name = gen.generate_elf_name()
dwarf_name = gen.generate_dwarf_name()
orc_name = gen.generate_orc_name()

# Generate with seed (reproducible)
name = gen.generate_elf_name(seed=12345)  # Always same result

# Generate batch
names = gen.generate_batch('human', count=10)
for name in names:
    print(name)

# Generic method (useful for dynamic race selection)
name = gen.generate_name('dwarf')
```

## How It Works

Names are generated by combining syllables from curated databases:

- **First names**: Start syllable + End syllable
- **Surnames**: Prefix + Suffix (except orcs, which use titles)

Each race has 50+ syllables per category, resulting in millions of possible combinations.

### Race-Specific Rules

**Humans**: Medieval European feel (Germanic, Celtic, Anglo-Saxon)
- Examples: Gareth, Aldric, Branna
- Surnames: Occupation or nature-based (Ironforge, Stonebridge)

**Elves**: Flowing, melodic, vowel-heavy
- Soft consonants: l, r, th, v, n, s
- Surnames: Nature and celestial themes (Moonwhisper, Starweaver)

**Dwarves**: Short, hard consonants
- Norse/Germanic influence
- Surnames: Metals, stones, crafts (Ironfoot, Stonehammer)

**Orcs**: Guttural, harsh sounds
- 50% chance of brutal title
- Examples: Grishnak the Scarred, Ugluk Bonecrusher

## Data Format

The `name_data.json` file contains syllable databases:

```json
{
  "human": {
    "first_start": ["gar", "eth", "ald", ...],
    "first_end": ["ric", "win", "dor", ...],
    "surname_prefix": ["Iron", "Stone", "Wood", ...],
    "surname_suffix": ["forge", "bridge", "field", ...]
  },
  "elf": { ... },
  "dwarf": { ... },
  "orc": { ... }
}
```

## Customization

Want to add your own syllables or create new races?

1. Edit `name_data.json`
2. Add arrays of syllables following existing patterns
3. For new races, add generation method to `NameGenerator` class
